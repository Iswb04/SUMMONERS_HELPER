# Como Rodar o Summoners Helper

Este projeto consiste em uma API (Backend) e uma Interface Gráfica (Frontend) moderna. Para que tudo funcione corretamente, siga estes passos:

## 1. Instalar Dependências
Abra o terminal e instale as bibliotecas necessárias:
```bash
pip install requests customtkinter fastapi uvicorn
```

## 2. Iniciar a API (Servidor Local)
A interface e a população do banco dependem da API estar rodando.
Abra um terminal e execute:
```bash
cd league_code
uvicorn API_main:app --reload
```
**MANTENHA ESTE TERMINAL ABERTO!**

## 3. Popular o Banco de Dados
Se o arquivo `db.sqleague` não existir ou estiver vazio, use este script para enchê-lo (com a API do passo 2 rodando):
Abra um **SEGUNDO** terminal e execute:
```bash
cd league_code
python league_main.py
```

## 4. Iniciar a Interface Gráfica (Bonitona!)
Agora você pode abrir a interface moderna:
No terminal, execute:
```bash
cd league_code
python league_view.py
```

---
### O que eu mudei:
1.  **Interface Moderna**: O `league_view.py` agora usa `customtkinter`. Tem modo escuro, botões arredondados e um visual muito mais profissional.
2.  **Melhoria no league_main.py**: Agora, se você tentar rodar o script sem a API estar ligada, ele vai te dar uma mensagem de erro amigável em vez daquele monte de texto técnico (Traceback).
3.  **Organização**: Adicionei este arquivo de instruções para facilitar sua vida.

Divirta-se com seu novo App!
